# Dynasty Spin Royale

Build an eight-player historic fantasy roster by spinning two players and choosing one. Trade rookie picks for guaranteed upgrades, balance fantasy points against remaining Dynasty Value, and compete on the live Top 100 leaderboard.

- **Play:** https://domenicmenta.github.io/dynasty-spin-royale/
- **Submission packet:** [SUBMISSION.md](SUBMISSION.md)
- **Scoring:** Full PPR, four-point passing touchdowns
- **Player pool:** 4,000+ NFL player-seasons, position-adjusted rarity

## Run locally

```bash
pnpm install
pnpm dev
```

Use `pnpm build` for the hosted application and `pnpm build:pages` for the GitHub Pages build.
